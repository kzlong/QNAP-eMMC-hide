# QNAP eMMC 隐藏（fnOS）

威联通 QNAP 安装 fnOS 后，原厂系统使用的 eMMC 启动存储及其分区 仍然会被 fnOS 的 Linux 内核识别，在fnOS文件管理器中以外接硬盘方式挂载。

## 功能特性

fnOS启动后，自动卸载指定的 QNAP 原厂 eMMC 分区挂载点，避免它们出现在 fnOS 文件管理器中。

> **注意**：此项目只对以下设备分区进行检查：`/dev/mmcblk0p1`、`p2`、`p3`、`p5`、`p6`、`p7`，且只卸载挂载到 `/vol00/RemovableDisk` 或 `/vol00/RemovableDisk_*` 的目标。不会格式化或修改分区内容。请在自己的设备上检查脚本后再安装。

## 版本：1.0.0 

- 服务状态、分区挂载状态、日志查看、启动/停止和立即隐藏功能。
- 网页服务默认监听 `127.0.0.1:9528`，仅允许 NAS 本机访问。

## 安全说明

管理页面当前没有身份认证，且 Web 服务监听所有网络接口。仅建议在可信任的局域网使用；不要将 TCP `9528` 映射到公网。若设备处于不可信网络，请先增加认证或将服务限制在本机/可信接口。
